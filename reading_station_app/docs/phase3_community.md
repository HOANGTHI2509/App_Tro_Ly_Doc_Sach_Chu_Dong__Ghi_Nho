# 👥 Giai Đoạn 3: Mạng Xã Hội (Community)
**Thời gian**: 4 tuần  
**Mục tiêu**: Xây dựng "Vòng tròn Tin cậy"

## 3.1. Module "Friendships"
- Features: Add/Accept/Reject friends, search users.
- Data: `Friendship` model.

## 3.2. Module "Activity Feed"
- Features: Social feed showing friends' reading activities.
- Data: `Activity` model.

## 3.3. Module "Social Recommendations"
- Features: "3 friends also read this", reviews from friends.
