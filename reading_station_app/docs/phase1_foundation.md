# 📱 Giai Đoạn 1: Nền Tảng (Foundation)
**Thời gian**: 4-6 tuần  
**Mục tiêu**: Xây dựng core features để user có thể quản lý thư viện và ghi chú

## 1.1. Module Authentication (Xác thực)
- Screens: Splash, Login, Register, Forgot Password.
- Services: `FirebaseAuthService`.
- State: `AuthProvider`.

## 1.2. Module "Thư viện Cá nhân" (My Library)
- Tabs: Want to Read, Reading, Read.
- Features: Add book (API/Manual), Update progress, Search online.
- Data: `Book`, `UserBook` models.

## 1.3. Module "Ghi chú Cơ bản" (Basic Notes)
- Features: Create/Edit/Delete text notes, Page numbers, Tags.

## 1.4. Module "Cài đặt & Profile" (Settings & Profile)
- Features: Profile editing, User stats (streak, total books), Settings (theme, notifications).
